# kspo_parking_collector
올림픽공원 주차대수 수집
(올림픽공원 내 동2/남2/북2 주차현황)
- 서비스키 : 변수명 ApiKey - 출력값: parking_sum 주차대수 - 샘플데이터: parking_sum : 2600
- 데이터 한계	메시지설명: 0000 (정상처리), 9999 (서비스 점검중)

## 데이터 설명
- 차일시,출차일시, 입차일 을 기준으로 주차대수를 확인하고 있습니다
추가 데이터
> 올림픽공원 주차장 내 전체 주차구역에 대한 2025년도 차량에 대한 입출차 정보입니다. 입차일시,출차일시, 입차일, 주차구역 정보로 구성 되어있습니다. 제공되는 데이터양이 방대하여 2025년에 대한 입출차에 대한 정보만 제공합니다. 다른 연도에 대한 주차정보도 연 단위로 개방할 예정입니다. 총 약240만건에 대한 입출차 정보를 제공하고 있습니다. 장기 주차인경우에는 종료일이 표기가 되어 있지 않을수도 있습니다. 데이터 건수가 많아 분석 전용 소프트웨어를 이용해주시기 바랍니다.
> https://www.data.go.kr/data/15159093/openapi.do
